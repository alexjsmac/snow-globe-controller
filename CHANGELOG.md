## [0.1.0] - 2025-11-15

### Added

- Initial release of Snow Globe Controller
- Christmas theme selection system (Color, Pattern, Effect)
- Real-time queue management with Firebase
- TouchDesigner integration for visual installations
- Admin dashboard for queue monitoring
- Session recording to Firestore
- 60-second turn-based system
- Automatic queue progression
- Theme value reset to "none" when queue is empty
- Comprehensive test suite
- CI/CD with GitHub Actions
- Code quality tools (ESLint, Prettier)

### Features

- **Theme Selection**: 3x3 grid of options (colors, patterns, effects)
- **Queue System**: Fair FIFO queue with real-time updates
- **Real-time Updates**: Firebase Realtime Database integration
- **Session Tracking**: Firestore-based analytics
- **Admin Tools**: Password-protected dashboard
- **Scripts**: Queue reset, trend analysis, token generation

### Technical

- Next.js 15.5 with React 19
- TypeScript with strict mode
- Firebase Realtime Database + Firestore
- Tailwind CSS for styling
- Jest for testing (50% coverage minimum)
- ESLint + Prettier for code quality

### Documentation

- Comprehensive README with setup instructions
- TouchDesigner integration guide
- Admin dashboard documentation
- Database structure documentation
- Contributing guidelines
- Security policy

### Known Issues

- None at initial release

### Migration Notes

- First release - no migration needed
